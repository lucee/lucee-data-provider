# Lucee Data provider

This repo contains the application code for the following services used by Lucee

* https://download.lucee.org — already on Google Cloud Run (`apps/download8`, service `lucee-data-provider`)
* https://update.lucee.org and https://extension.lucee.org — the REST app in [`apps/updateserver`](apps/updateserver); live traffic is still on Pixl8, Cloud Run setup is in that README
