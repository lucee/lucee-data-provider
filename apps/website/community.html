How to contribute

  • Report a bug or request a feature. Create a ticket in Jira. See troubleshooting first.
  • Send a pull request. Read CONTRIBUTING.md and the release cycle and branching guide to pick the right target branch.
  • Improve the documentation. The docs are open source in lucee-docs, and every docs page has an edit link.
  • Answer a question on the forum or in Slack.
  • Support the project financially on Open Collective.

Please follow our community guidelines in the forum and other community spaces.
