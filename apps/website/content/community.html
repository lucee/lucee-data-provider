Community

Lucee is a community project. Ask questions, report bugs, improve the docs or send a pull request.

Where to find us

Forum

dev.lucee.org

Questions, discussion, release announcements and the Lucee mailing list.
Chat

CFML Slack

Get help with CFML or help others. Lucee has a channel there.
Code

GitHub

The Lucee source code, pull requests and releases. More repositories live under github.com/lucee.

Issues

Jira (LDEV)

The issue tracker for bugs and feature requests.
Video

YouTube

Tutorials and tips on the Lucee channel.

How to contribute

  • Report a bug or request a feature. Create a ticket in Jira. See troubleshooting first.
  • Send a pull request. Read CONTRIBUTING.md and the release cycle and branching guide to pick the right target branch.
  • Improve the documentation. The docs are open source in lucee-docs, and every docs page has an edit link.
  • Answer a question on the forum or in Slack.
  • Support the project financially on Open Collective.
