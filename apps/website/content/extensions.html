Extensions

Extensions add capabilities to Lucee: datasource drivers, cache providers, resource providers such as S3 and Redis, image handling, PDF generation, and more.

Find an extension

The extension listing lives on the download site. Each extension is a self-contained .lex package. Pick one to see its versions and installation instructions.

Browse extensions

Maven coordinates

Extensions are published to Maven Central. An extension is identified by its Maven coordinates, groupId:artifactId:version. Lucee's own extensions use the group org.lucee and an artifact name ending in -extension. The listing on the download site shows the coordinates of every extension, for example org.lucee:administrator-extension. Other publishers, such as io.forgebox, use their own group.

The released .lex files can be fetched from repo1.maven.org/maven2/org/lucee/.

In Lucee 8 the coordinates are what you declare in .CFConfig.json to install an extension. Pin the version for reproducible deployments:

{
  "extensions": [
    { "maven": "org.lucee:s3-extension:2.0.2.21" },
    { "maven": "org.lucee:redis-extension:3.0.0.56" }
  ]
}

Other ways to install an extension, such as the Lucee Administrator or the deploy directory, are covered in the guide below.
