A high-performance, open source CFML server written in Java.

Free to use under the LGPL 2.1. Runs on the JVM as a servlet, so it works with servlet containers such as Apache Tomcat and Eclipse Jetty. This is the starting point for everything Lucee.

Get started

Install

Docker

docker run -d -p 8888:8888 lucee/lucee:latest

Docker guide · Docker Hub

CommandBox

box server start

CommandBox guide · Install CommandBox

Run it in an empty directory. CommandBox starts an embedded Lucee server. Other options (JAR, Express, WAR, …) are on the download page.

Hello world

Create index.cfm in your web root. With CommandBox that is the directory you started the server in. Use tags or script, your choice.

Tags

<cfset name = "World">
<cfoutput>Hello #name#!</cfoutput>

Script

<cfscript>
	name = "World";
	echo( "Hello #name#!" );
</cfscript>

Refresh the browser. Using Docker? Mount your code into the container, see the Docker guide.
