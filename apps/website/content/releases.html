Version numbers and branches

A Lucee version has four parts, MAJOR.MINOR.PATCH.BUILD, plus an optional qualifier: -SNAPSHOT (development build), -ALPHA or -BETA (early builds), -RC (release candidate). A final release has no qualifier.

The source repository has one long-lived branch per version line. Bug fixes go to 7.1, breaking-change fixes to 8.0, and new features to 9.0. Details are in the release cycle and branching guide.
